## 系统一：在线监测预警系统

**URL**: http://online.chinatsi.com/index.html
**标题**: 监测预警
**归属**: 中国技术交易所

### 系统概述

这是一个**行业资讯与政策监测平台**，主要为钢铁及相关行业的企业提供：
- 政策资讯追踪
- 行业数据分析
- 地图可视化
- 监测预警报告

### 技术架构

#### 1. 前端框架
- **UI框架**: H-ui (国产后台UI框架)
- **核心库**:
  - jQuery 1.9.1
  - template.js (JavaScript模板引擎)
  - layer.js (弹层组件)

#### 2. 服务器环境
- **Web服务器**: nginx/1.12.1 (较旧版本)
- **通信协议**: HTTP (未启用HTTPS)

### 安全问题

#### 🔴 高危问题

1. **未使用HTTPS加密**
   - 整个站点使用HTTP明文传输
   - 登录凭证、Cookie可被中间人攻击截获
   - 密码以明文形式传输

2. **后端IP暴露**
   - 直接暴露内网IP `118.126.142.187`
   - 泄露架构信息，便于攻击者侦查

3. **过时的Nginx版本**
   - nginx/1.12.1 (2017年发布)
   - 存在已知安全漏洞（CVE-2017-7529等）

4. **WebSocket未加密**
   - 使用 `ws://` 而非 `wss://`

#### 🟡 中危问题

1. **前端Cookie管理**
   - Cookie设置在 `.chinatsi.com` 域下共享
   - 可能存在子域Cookie劫持风险

2. **客户端Cookie存储敏感信息**
   - userid、tel、token均存储在Cookie中
   - 易受XSS攻击窃取

3. **调试信息暴露**
   - 代码中包含内网测试地址 `192.168.0.16`

## 安全风险汇总

两个系统共有的安全问题：

1. ⚠️ **全HTTP传输** - 无HTTPS加密
2. ⚠️ **后端IP暴露** - `118.126.142.187`
3. ⚠️ **WebSocket未加密** - `ws://` 协议
4. ⚠️ **过时的服务器版本** - nginx/1.12.1

### 建议改进

#### 安全加固
1. 🔴 **紧急启用HTTPS** - 购买SSL证书，全站强制HTTPS跳转
2. 🔴 **升级Nginx** - 升级到最新稳定版
3. 🔴 **隐藏后端IP** - 使用反向代理，不要暴露真实服务器IP
4. 🟡 **启用WAF** - 部署Web应用防火墙
5. 🟡 **增强Cookie安全** - 添加HttpOnly、Secure标志

#### 架构优化
1. 使用环境变量管理API地址，避免硬编码
2. 移除调试信息和内网地址
3. 升级前端依赖库（jQuery 1.9.1 → 3.x+）
