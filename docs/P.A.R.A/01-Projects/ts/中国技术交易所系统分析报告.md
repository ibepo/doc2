## 系统一：在线监测预警系统

**URL**: http://online.chinatsi.com/index.html
**标题**: 监测预警
**归属**: 中国技术交易所

### 系统概述

这是一个**行业资讯与政策监测平台**，主要为钢铁及相关行业的企业提供政策资讯追踪、行业数据分析、地图可视化和监测预警报告。

### 安全问题

#### 🔴 高危问题

| 问题 | 风险 | 影响 |
|------|------|------|
| 未使用HTTPS | 中间人攻击 | 凭证截获、数据泄露 |
| 后端IP暴露 | 架构信息泄露 | 便于攻击者侦查 |
| nginx/1.12.1过时 | 已知漏洞 | CVE-2017-7529等 |
| WebSocket未加密 | 数据窃听 | 实时数据泄露 |

#### 🟡 中危问题

| 问题 | 风险 |
|------|------|
| Cookie子域共享 | 跨子域Cookie劫持 |
| Cookie存储敏感信息 | XSS攻击窃取 |
| 内网地址暴露 | 信息泄露 |

## 安全风险汇总

### 共有安全问题

| 风险等级 | 问题 | 系统1 | 系统2 | 影响 |
|----------|------|-------|-------|------|
| 🔴 高危 | HTTP明文传输 | ✓ | 部分 | 数据截获 |
| 🔴 高危 | 后端IP暴露 | ✓ | ✓ | 架构泄露 |
| 🔴 高危 | 过时的服务器版本 | ✓ | ✓ | 已知漏洞 |
| 🟡 中危 | WebSocket未加密 | ✓ | - | 数据泄露 |
| 🟡 中危 | Cookie安全问题 | ✓ | ✓ | 会话劫持 |
| 🟡 中危 | 硬编码敏感信息 | ✓ | ✓ | 信息泄露 |

### 系统一特有风险

1. **jQuery 1.9.1过时** - 存在已知XSS漏洞
2. **IE8兼容性代码** - html5shiv和respond.min.js不再维护
3. **明文密码传输** - 登录表单未加密
4. **内网地址暴露** - 192.168.0.16

### 系统二特有风险

1. **混合使用jQuery和Axios** - 代码不一致
2. **硬编码Token** - `token=chinatsi123`
3. **内嵌iframe** - 潜在点击劫持风险
4. **部分API仍用HTTP** - 118.126.142.187

## 建议改进方案

### 安全加固

#### 紧急处理 (🔴 高优先级)

1. **启用HTTPS**
   ```
   - 购买SSL证书
   - 全站强制HTTPS跳转
   - 升级WebSocket为WSS
   ```

2. **隐藏后端IP**
   ```
   - 使用反向代理
   - 通过域名访问API
   - 配置防火墙规则
   ```

3. **升级服务器**
   ```
   - nginx → 最新稳定版
   - 修复已知漏洞
   ```

4. **移除敏感信息**
   ```
   - 删除内网地址
   - 移除硬编码token
   - 使用环境变量管理配置
   ```

#### 中期改进 (🟡 中优先级)

1. **增强Cookie安全**
   ```javascript
   // 添加安全标志
   document.cookie = "token=xxx; Secure; HttpOnly; SameSite=Strict"
   ```

2. **升级前端依赖**
   ```
   - jQuery 1.9.1 → 3.6+
   - 移除IE兼容代码
   - 更新所有npm包
   ```

3. **API安全**
   ```
   - 实现请求签名
   - 添加速率限制
   - 启用CORS白名单
   ```

### 架构优化

#### 系统一改进

```
传统架构 → 现代化改造
├── H-ui → Vue 3 + Element Plus
```
