# 钢铁市场监控核心指南

## 📊 监控总览

基于2026年钢铁市场"新周期开启，景气扩张，价格中枢上移"的核心判断，建立全方位监控体系，重点关注以下三大维度：

---

## 🌐 宏观面监控（核心：周期共振判断）

### 1. 政策环境监测
**监测频率**：每日/每周
**关注重点**：
- **国内政策**
  - 专项债发行进度
  - 化债进展
  - 货币政策松紧

- **国际政策**
  - 美联储利率
  - 美元指数
  - 欧日财政刺激

- **共振信号**
  - 双宽松 = 强看涨
  - 双收紧 = 强看跌
  - 一松一紧 = 需判断主导因素

### 2. 经济指标监测
**监测频率**：每月/每季度
**关注重点**：
- **关键数据**
  - PMI（50为分界线）
  - 固定资产投资
  - 出口数据

- **预警阈值**：
  - PMI连续2月<50 → 经济下行风险
  - 投资增速<5% → 投资不足风险
  - 出口增速↓10% → 外需减弱风险

### 3. 周期共振监测
**监测频率**：每周
**关注重点**：
- **国内周期**
  - "十五五"项目落地
  - 信用扩张速度

- **国际周期**
  - 美元指数
  - CRB大宗商品指数

- **判断方法**
  - 寻找政策松紧的共振时机
  - 国内政策宽松 + 美元宽松 = 强共振看涨
  - 国内政策收紧 + 美元收紧 = 强共振看跌

---

## 📈 技术面监控（核心：V/W型反转判断）

### 1. 价格监测
**监测频率**：每日/实时
**关注重点**：
- **期货重点**
  - 螺纹钢主力合约
  - 铁矿石主力合约

- **现货重点**
  - 各区域钢材价格
  - 铁矿石进口价格

- **关键信号**
  - 1-2季度：警惕春季需求不足导致探底
  - 2季度后：关注投资增长显现的上行信号
  - 日波动超过3%需要重点关注

### 2. 供需监测
**监测频率**：每月/每季度
**关注重点**：
- **供给端**
  - 粗钢产量（9.8亿吨基准）
  - 高炉开工率
  - 钢厂库存、社会库存

- **需求端**
  - 房地产新开工
  - 基建项目落地
  - 制造业订单

- **库存监测**
  - 钢厂库存、社会库存变化趋势
  - 库存连续4周上升预警需求不足

### 3. 资金流向监测
**监测频率**：每日/每周
**关注重点**：
- **期货持仓**
  - 前20名机构持仓变化
  - 多空持仓比变化

- **股票资金**
  - 钢铁板块资金流向
  - 宝钢、鞍钢等龙头表现

- **信号判断**
  - 连续3天净流入 = 看涨信号
  - 连续3天净流出 = 看跌信号
  - 持仓比持续上升 = 多头信心增强

## 📢 舆情与情绪监控（核心：市场预期验证）

### 1. 新闻舆情监测
**监测频率**：每日
**监测渠道**：
- 新华社、我的钢铁网
- 路透社、彭博社
- 中国钢铁工业协会

**关注关键词**：
- 产能置换、环保限产
- 出口退税、化债
- 新周期、景气度、复苏

**情绪评估**：
- 极度悲观：负面新闻占比>70%
- 谨慎乐观：负面新闻占比30-70%
- 乐观情绪：负面新闻占比<30%

### 2. 社交媒体监测
**监测频率**：每日
**平台覆盖**：
- 雪球、微博
- Twitter、TradingView
- 东方财富股吧

**关注指标**：
- 讨论热度：话题讨论量、转发量
- 情绪指数：正面/负面评论比例
- 专业度：行业专家参与度
- 国际关注度：外资评论、国际机构观点

**预警信号**：
- 突发负面舆情：股价/价格3天内下跌>5%
- 专业观点分歧：多空观点比例>3:1
- 国际机构一致看空/看多

### 3. 市场预期监测
**监测频率**：每周/每月
**预期调查**：
- 分析师观点汇总
- 问卷调查
- 期货贴水：期现价差反映市场预期

**价格预期**：
- 未来3个月价格预期
- 未来6个月价格预期
- 未来12个月价格预期

**周期预期**：
- 见顶/见底时间预期
- 新周期启动时间预期

## 🚨 三级预警机制

### 🔴 红色预警（高风险）
**触发条件**：
- PMI连续3个月低于45
- 房地产投资增速下降>15%
- 钢材库存连续6周上升>20%
- 国际机构一致看空
- 突发重大政策转向

**应对策略**：
- 减仓控制风险
- 观望等待信号
- 关注政策应对措施

### 🟠 橙色预警（中风险）
**触发条件**：
- PMI连续2个月低于50
- 价格波动率超过5%
- 资金连续流出>5天
- 负面舆情占比>60%

**应对策略**：
- 适度减仓，控制仓位
- 密切关注关键支撑位
- 做好止损准备

### 🟡 黄色预警（提醒）
**触发条件**：
- 重要数据发布前1-2天
- 政策会议期间
- 节假日前后

**应对策略**：
- 降低操作频率
- 避免追涨杀跌
- 关注市场情绪变化

## 💡 投资策略建议

### 🎯 1-2季度策略（防守阶段）
**关注重点**：
- 春季需求成色
- 政策托底力度
- 探底风险防范

**操作建议**：
- 轻仓试探，控制风险
- 观望为主，等待信号
- 关注1-2季度之间春季需求成色不足，引发价格探底

### 🚀 2季度后策略（进攻阶段）
**关注重点**：
- 投资增长显现
- 价格上行通道
- 周期红利把握

**操作建议**：
- 逐步建仓，把握节奏
- 关注2季度以后投资和贷款增长显现
- 把握慢牛周期的震荡上行机会
