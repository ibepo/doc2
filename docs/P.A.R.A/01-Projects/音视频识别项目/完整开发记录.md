# 播客字幕自动化系统 - 完整开发记录

## 项目背景

用户需求：创建一个能够从播客/视频 URL 自动提取音视频、生成字幕的自动化系统

**核心需求**：
1. 从播客/视频页面 URL 中提取音视频链接
2. 下载音视频内容
3. 使用 ASR（语音识别）生成字幕
4. 提供两种交互方式：
   - GUI 界面：一键启动的桌面应用
   - MCP 服务器：可被 LLM 调用的服务接口

**技术栈**：Python


**关键技术点**：
- 使用正则表达式检测平台
- 使用 BeautifulSoup 解析 HTML
- 提取 meta 标签中的音视频链接

### 3.3 代码实现

```python
# 关键代码片段
def _parse_xiaoyuzhou(self, url: str, result: Dict) -> Dict:
    response = self.session.get(url, timeout=self.timeout)
    soup = BeautifulSoup(response.text, 'html.parser')

    # 提取标题
    title_elem = soup.find('meta', property='og:title')
    result['title'] = title_elem.get('content', '').strip()

    # 提取音频 URL
    audio_elem = soup.find('meta', property='og:audio')
    if audio_elem:
        result['audio_url'] = audio_elem.get('content')
        result['type'] = 'audio'
```

```python
    def __init__(self, model_name: str = "SenseVoiceSmall"):
        """初始化 ASR 模型"""
        from funasr import AutoModel
        self.model = AutoModel(
            model=f"iic/{model_name}",
            vad_model="fsmn-vad",
            device=self.device
        )

    def transcribe(self, audio_path: str) -> List[Dict]:
        """转录音频，返回带时间轴的文本片段"""
        result = self.model.generate(input=audio_path)
        # 解析结果，提取时间轴和文本
        return self._parse_result(result)

    def generate_srt(self, segments: List[Dict]) -> str:
        """生成 SRT 格式字幕"""
        # 标准时间轴格式：HH:MM:SS,mmm
```

**输出格式**：
- **SRT**：标准字幕格式，带时间轴
- **TXT**：纯文本，带时间戳
- **Markdown**：文档格式，包含元数据

### 5.3 时间轴格式化

```python
def _format_srt_time(self, seconds: float) -> str:
    """格式化为 SRT 时间格式"""
    td = timedelta(seconds=seconds)
    hours, remainder = divmod(td.seconds, 3600)
    minutes, seconds = divmod(remainder, 60)
    milliseconds = td.microseconds // 1000
    return f"{hours:02}:{minutes:02}:{seconds:02},{milliseconds:03}"
```

## 第七步：创建 MCP 服务器

### 7.1 MCP 协议理解

**MCP (Model Context Protocol)**：
- 标准 JSON-RPC 2.0 协议
- stdin/stdout 通信
- 支持工具调用

### 7.2 实现细节

创建文件：`src/mcp/server.py`

**核心类**：`PodcastSubtitleMCP`

**主循环**：
```python
async def start(self):
    while True:
        line = sys.stdin.readline()
        request = json.loads(line)
        response = await self.handle_request(request)
        print(json.dumps(response), flush=True)
```

**工具定义**：
```python
tools = [
    {
        "name": "generate_subtitle",
        "description": "从播客/视频 URL 自动生成字幕",
        "inputSchema": {
            "type": "object",
            "properties": {
                "url": {"type": "string"},
                "output_formats": {"type": "array"},
                "language": {"type": "string"}
            }
        }
    }
]
```

### 7.3 工具调用处理

```python
async def call_tool(self, request: dict) -> dict:
    params = request.get("params", {})
    tool_name = params.get("name")
    arguments = params.get("arguments", {})

    if tool_name == "generate_subtitle":
        result = await self.generate_subtitle(arguments)

    return {
        "jsonrpc": "2.0",
        "id": request.get("id"),
        "result": {
            "content": [{"type": "text", "text": result}]
        }
    }
```

## 开发决策记录

### 决策 1：选择 Gradio 作为 GUI 框架

**选项对比**：
- Tkinter：Python 内置，但界面简陋
- PyQt5：功能强大，但学习曲线陡峭
- Gradio：快速开发，Web 界面，推荐

**选择**：Gradio

**理由**：
1. 代码量少（~250 行 vs PyQt 需要 ~500 行）
2. 自动处理 Web 服务器
3. 内置进度条和文件下载
4. 支持分享链接（可选）

### 决策 2：选择 SenseVoice 作为默认模型

**选项对比**：
- Whisper：多语言，但中文效果一般
- Paraformer：中文专用，工业级
- SenseVoice：多语言+中文优化，带标点

**选择**：SenseVoiceSmall

**理由**：
1. 中文效果好
2. 自动添加标点符号
3. 支持多语言（zh/en/ja/ko）
4. 参数量适中（234M）

### 决策 3：使用 ModelScope 下载模型

**原因**：
- 国内服务器，下载速度快
- 不需要翻墙
- 稳定可靠

**实现**：
```python

model = AutoModel(model="iic/SenseVoiceSmall")
# 自动从 ModelScope 下载
```

## 遇到的挑战和解决方案

### 挑战 1：模型加载慢

**问题**：FunASR 模型首次加载需要几分钟

**解决方案**：
1. 使用 ModelScope 国内镜像
2. 显示加载进度
3. 提示用户耐心等待

### 挑战 2：不同平台的 URL 格式差异

**问题**：每个平台的 URL 结构不同

**解决方案**：
1. 使用正则表达式检测平台类型
2. 为每个平台编写专门的解析器
3. 使用 yt-dlp 作为通用方案

### 挑战 3：长时间音频处理

**问题**：2 小时音频需要处理很长时间

**解决方案**：
1. 使用 VAD（语音活动检测）分段处理
2. 显示进度条
3. 允许用户中断
