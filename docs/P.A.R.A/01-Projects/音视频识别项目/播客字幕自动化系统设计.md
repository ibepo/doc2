# 播客字幕自动化系统 - 项目设计

## 项目概述

一个能够从播客/视频页面 URL 自动提取音视频、生成字幕的自动化系统，提供两种交互方式：
1. **GUI 界面** - 一键启动的桌面应用
2. **MCP 服务器** - 可被 LLM 调用的服务接口

## 模块设计

### 1. URL 解析器 (url_parser.py)

**功能**：
- 从网页 URL 中提取音视频链接
- 支持主流播客/视频平台
- 自动识别内容类型（音频/视频）

**支持平台**：
- 播客：小宇宙、喜马拉雅、荔枝FM、Apple Podcasts
- 视频：B站、YouTube、优酷、腾讯视频
- 音频：通用 MP3/WAV 链接

## 配置文件

```yaml
# config.yaml
asr:
  model: "SenseVoiceSmall"  # 或 Fun-ASR-Nano
  device: "cuda"            # cuda/cpu
  language: "auto"          # auto/zh/en

output:
  format: "srt"             # srt/txt/md
  encoding: "utf-8"
  directory: "./outputs"

downloader:
  audio_format: "wav"
  sample_rate: 16000
  channels: 1

gui:
  port: 7860
  share: false              # 是否创建公网链接

mcp:
  host: "localhost"
  port: 3000
```

## 快速开始

### 安装
```bash
git clone https://github.com/your-repo/podcast-subtitle-generator.git
cd podcast-subtitle-generator
pip install -r requirements.txt
```

### 启动 GUI
```bash
python gui_launcher.py
# 浏览器自动打开 http://localhost:7860
```

### 启动 MCP
```bash
python mcp_server.py
# 服务运行在 http://localhost:3000
```
