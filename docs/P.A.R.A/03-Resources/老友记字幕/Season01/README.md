## 使用方法

### 方法 1：使用视频播放器

大多数现代视频播放器（如 VLC、MPC-HC、PotPlayer 等）支持外挂字幕：

1. 播放对应的视频文件
2. 加载同名的 SRT 字幕文件
3. 调整字幕时差（如果需要）

### 方法 2：重命名匹配

将字幕文件重命名为与视频文件相同的名称（扩展名除外）：

```
Friends.S01E01.720p.BluRay.mkv
Friends.S01E01.720p.BluRay.srt
```

### 方法 3：批量处理

如果视频文件名与字幕文件名不匹配，可以使用脚本批量重命名：

```bash
# 示例：将字幕重命名为匹配视频格式
for i in $(seq -w 1 24); do
  mv "friends.s01e${i}.720p.bluray.x264-psychd.srt" "Friends.S01E${i}.720p.BluRay.srt"
done
```

## 注意事项

1. **时差调整**: 如果字幕与视频不同步，可能需要调整时差（通常 ±0.5-2 秒）
2. **编码问题**: 如果字幕显示乱码，请检查播放器的字符编码设置（应设置为 UTF-8 或 ANSI）
3. **版本匹配**: 这些字幕是为 720p BluRay 版本制作的，如果使用其他版本的视频可能需要调整
