# 现在的搜索引擎，快被AI垃圾淹成赛博粪坑了。

实在有点憋不住了，AI生成的一些垃圾，已经对我的日常生活中的一些小事，造成极大的困扰了。昨天新年，白天我想找一张蛇的动漫风格参考图，来做个新年贺卡。然而就是这么简单的一次搜索，让我真的觉得，现在的互联网，越来越不对劲了。我就在搜索引擎搜了一下关键词**“蛇 动漫”** 。第一页的结果是这样，那一瞬间，我只觉得寒意从电脑屏幕爬上脊背。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURog4w69tNn3Tgvu2QKyg3ZfP2hXetCzqWLL3giaVbcagyn5MPxzFia1GcOo0DFLK5eyyYscx1pZ4xwg/640?wx_fmt=png&from=appmsg)为了文章阅读方便，我直接给大家标注了：**所有被斜线划掉的，都是AI生成的。**  
嗯...就第三排第三张是真人画师的...其他，全是AI。。。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURog4w69tNn3Tgvu2QKyg3ZfBA7GNOia0dLm2WjuFRvIB6Qc7FIF39QUOFyoxRA6uu27aWzJvIP72ww/640?wx_fmt=png&from=appmsg)这些油腻的要死的画风，垃圾的审美，真的一眼劣质AI，我还怕我是有眼不识泰山认错了，一张一张点进去确认了，最后确认，全都是AI。没一张是能用的参考。。。这还是搜到结果图的第一页。我又翻了3、4页，才开始有部分的真人的图开始出现。  
更恐怖的是，我发现不只是这个关键词，低质量的AI内容已经悄无声息地，蔓延到了互联网的每个角落。比如**“牡丹”** 这个关键词，我啥画风要求都没加。搜出来的结果都不用我标注了，全是。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRVofjW9XgvjSUIrp5Vnv4xnXicmNBVNyBwGvD0RrjAnCuGwdON95lnyng/640?wx_fmt=png&from=appmsg)还有AI重灾区，**“龙”** 。除了一张Q版的，全都是AI，一点一个准。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRVJ5eXWdiaRJT07LA5zI7zqPWbfjPSdMzwXK5vyAkRcowlPsF2F2EGxTw/640?wx_fmt=png&from=appmsg)越搜越觉得诡异。。。我又自作聪明地觉得，这大概是搜索引擎的问题，那我去一些摄影、设计素材站找灵感，总能避开吧。没想到，防不胜防啊。本来我看到素材网站有“屏蔽AI创作的图片”的选项，以为终于能找到正常的参考了。搜出的前10张图里，6个被我划掉的是AI。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRVEnicNZXlFz3mIzkIfuFh5HlxGXD7Aek6iasJ42DTooeZic2lOxWYv1jCg/640?wx_fmt=png&from=appmsg)说真的，这帮AI图连装都懒得装。你要是那种高质量的AI图也就算了。结果很大一部分都是结构崩坏、光影混乱、质感油腻，全特么是一个模子里刻出来的微do的玩意，普通人随便一看就知道是垃圾，更别说我这个天天和AI打交道的。看着这些垃圾图在图库里泛滥成灾，开始对我的日常小事产生一些影响，我突然就想问一个问题：**这些AI垃圾，它们到底是从哪儿冒出来的？** 挨个追溯图片来源，终于破案了，而且答案跟我预期的非常一致：这些AI图，基本全都都来自内容平台和社交媒体。最常见的来源，是短视频平台。光是一个“牡丹”的关键词，就让我顺藤摸瓜找到了好几个“复制人”账号。这些账号主页里几百条几乎一模一样的内容，连用的图和文案都是用同一个Prompt跑出来的。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRVQrmU4q3aRmKibcF0hfuCBBCrk1COAIMrhicUoJMrLdPfQOtpjWhGwYHA/640?wx_fmt=png&from=appmsg)![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRV516wpRUX5ibFm4hKeMtHmlicibqKUFWjvlTXKat1owyhMBvUIzRnykeibA/640?wx_fmt=png&from=appmsg)几百条重复的内容，都是AI生成的龙啊、牡丹的图片，配上各类网络鸡汤和励志语录和流行bgm，居然流量还不错，还有1w赞的东西。还有被复制人壁纸号疯狂入侵的内容平台。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRVFlnaIjiacfgsgYOVkuW40e0icyJWdibkuMTaTKqpMezRoZ5Xahc5mpNlw/640?wx_fmt=png&from=appmsg)这种壁纸号，全部都是复制人，我已经点开N个账号了，每个账号都是一样的，AI生图、AI文案，然后每个号每天发一条九宫格的AI垃圾。很烦，彻底让我的搜索引擎，变成了赛博粪坑。然后素材网站里的AI图，也一样，大部分来自图文内容平台。这些账号和内容，莫名让我想到之前很火的一个短视频：“黄龙江一派都带蓝牙，记住我给出的原理。。。”就是那种浓浓的人机感。他们孜孜不倦地发布几百条一模一样的内容，久而久之，经过算法的加持，这些垃圾就像癌细胞一样，侵蚀着互联网的每个角落。想想以前，我们已经习惯了水军在评论区刷存在感，现在又冒出一大批AI复制人在内容平台扎堆。其背后逻辑，依旧是“流量逐利”。创作者想靠流量变现，AI技术刚好给了他们最高效的轰炸手段，于是，一篇篇、一张张，制造成本接近于零的“AI垃圾内容”就这样撒向天下。互联网，尤其内容平台，需要内容来创造消费。为了激励创作者，基本所有的平台都有所谓的“流量激励”。其中最直观的，就是流量的直接变现。虽然这两年流量奖励砍了不少，但也是还有，且各大平台还是用各种“广告”、“合作”、“打赏”，五花八门的机会让创作者获利，以希望更多创作者继续为平台输出内容。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRVNxtYI90YeuW42zzY3uicvuqsRkBpLAfUBcN7oIN6GOY56J2k9D8CVlw/640?wx_fmt=png&from=appmsg)假设一个视频的播放量每提升1000，就能赚1毛现金，一条视频正经创作一周，可能也只能赚到个几十块。但用AI开N个复制人账号狂轰滥炸，一天发1000张图就跟喝水一样简单。积少成多，这帮人说不定比认真做内容的赚得还多。现在在短视频平台和二手交易网站一搜，满屏要教我发家致富的AI大师。![](https://mmbiz.qpic.cn/mmbiz_jpg/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRVLFw2dYic2YjYZK4namOuGtiaWlvTea1ZNugbLrtKzQKhsjibdBO58UKicw/640?wx_fmt=jpeg&from=appmsg)每个标题都噱头十足，反正也不吃亏，我也下单了一笔，看看这帮人到底在搞什么鬼。刚付款，对面就自动回复了一个网盘链接。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRVZKZMKFAOjiaBFRzsiaB4f02PnBZXDTLl6yKDBP88z1UvAx7AI1Cf7E9Q/640?wx_fmt=png&from=appmsg)别说，我还真加了。。。这帮人最后绕来绕去，最后还是想让你掏几百几千去进“高质量AI群”、“定制私域”。人们挥舞着AI的大旗，打着效率的幌子，却还是在干着最原始的割韭菜勾当。但真正让我感到不安的，还不止这些。我时常想：**当有一天，我们在信息海洋里再也找不到一条干净的河流时，该怎么办？** 淹没在搜索引擎里海量AI图像和文案之中的，不仅仅是我的创作灵感，还有我对这个世界的基本信任。更恶心的是，这些批量生产的垃圾会再被AI抓取、学习，垃圾迭代出更新鲜的垃圾，完成给用户赛博喂屎的大圆满境界。![](https://mmbiz.qpic.cn/mmbiz_png/OjgKEXmLURoQpVRicqx7au8LY0NLyRbRV9hroODpzphkO0tSPEgwiaOW8d0cUeY9TRUkmts953LOib3N9Ewu0r4Nw/640?wx_fmt=png&from=appmsg)在SEO领域，这种赛博喂屎的内容农场模式，当然也不是什么新鲜事，但是那个年代只有文字，而现在，所有模态都被全面入侵。  
我不知道未来还要经历多少相似的汹涌，但我始终坚信，好内容就像河床深处的珍珠，终究会被发掘。面对当下铺天盖地的AI垃圾，也终有人会站出来捍卫那份珍贵的、不可替代的人类表达。我们现在并不是无路可走，只是需要花更多力气，去捞起那些真正属于我们自己的东西。**去看、去听、去说，去坚持内容的源头清泉。** 要不然，在这信息大爆炸的年代，我们将失去的不仅仅是所谓的灵感，还有与灵感同在的那份真诚与信任。所以，请记住。当漫天的AI垃圾在夜空中坠落，当数据的洪流席卷而来，你还是可以冷静地拨开它们，继续寻找那盏微弱却不熄的灯火。它在那里。一直都在。
