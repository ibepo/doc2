在Obsidian中安装插件是一个简单直接的过程：

### **使用方法**

  
启用插件后，右键点击笔记中的任何一个块或标题，你会发现右键菜单中多了一个“Copy Block Link”选项。  
点击它，链接就会被复制到剪贴板上，接下来你就可以在其他笔记中粘贴这个链接进行引用了。
