### **什么是 Dataview？**

Dataview 简单来说就是一个为 Obsidian 量身定做的高级查询插件。你可以把它想象成 Obsidian 的超级放大镜，不仅能让你从笔记中找出你需要的内容，还能按照你的心意把这些内容整合起来，摆放得整整齐齐，像是给你量身定做的一样。

用更具体一点的话来说，Dataview 提供了一种类似 SQL 的查询语言，让你可以在笔记中进行数据筛选、排序、分析。无论是你随手记下的一些灵感，还是日常的任务清单，甚至是你那些埋在笔记里的小细节，Dataview 都能帮你一一挖出来，并呈现出一个你最想看到的样子。

### **Dataview 的主要功能**

要说 Dataview 最吸引人的地方，莫过于它的几个关键功能了。

#### **1\. 查询语言**

首先，Dataview 有一套自己独特的查询语言，虽然它基于 JavaScript，但别担心，这并不意味着你得精通编程才能用好它。其实，只要你懂一点点 SQL 的基本概念，就能轻松上手。

通过这套查询语言，你可以从你的笔记中提取数据、执行计算，甚至还能做一些复杂的逻辑操作。

举个例子吧，假如你想要找出所有含有特定标签的笔记，并按照某个自定义字段进行排序，这对于 Dataview 来说就是小菜一碟。只要一条简单的查询语句，你的笔记就能变得井井有条。

#### **2\. 动态视图**

其次，Dataview 还能根据你的查询结果动态生成视图。这是什么意思呢？就是说你可以把查询结果直接嵌入到 Obsidian 的笔记里，而且这些视图是动态更新的。比如，你可以创建一个任务列表，自动显示所有未完成的任务。每次你更新了笔记内容，视图也会随之更新，完全不用你手动去维护。

#### **3\. YAML 元数据支持**

说到 Obsidian 的元数据，很多人可能都用过 YAML。这种在文档顶部用 --- 围起来的块，可以储存笔记的各种属性信息。而 Dataview 就是基于这些元数据工作的。你可以在 YAML 中定义任何你需要的字段，然后通过 Dataview 查询这些字段，这样一来，你的笔记就不再是散乱的文本块，而是变成了一个结构化的数据库。

#### **4\. 与 Obsidian 的深度集成**

最后，Dataview 跟 Obsidian 本身的集成也是相当到位的。它的查询结果可以直接嵌入笔记，并且随着数据的更新而自动刷新，这让整个笔记系统更加智能化和灵活。你可以随时查看自己设定的视图，不用担心它们过时。

#### **数据来源**

首先，Dataview 从哪里获取数据呢？其实它就是从你的 Markdown 笔记中挖掘数据。主要有两个来源：一个是 Markdown 文档的 YAML 头部，另一个是内联字段。

  * **YAML 头部：** 在每篇 Markdown 文档的顶部，你可以用 YAML 格式来定义元数据，比如日期、标签、类别等等。这些数据都可以被 Dataview 读取和查询。

  * **内联字段：** 这是 Dataview 独有的一个功能，允许你直接在 Markdown 文档的正文里定义元数据。比如，你可以写 Deadline:: 2024-12-31，然后 Dataview 就可以根据这个字段来筛选或者排序你的笔记。




#### **查询方式**

一旦你在笔记里定义好了元数据，你就可以用 Dataview 的查询功能来玩转这些数据了。Dataview 提供了四种主要的查询方式：

  * **Dataview Query Language (DQL)：** 这是一种基于流水线的查询语言，类似 SQL，但更简洁。它非常适合做一些简单的查询和数据处理。

  * **Inline Expres****sions：** 你可以在 Markdown 文档中直接嵌入 DQL 表达式，这样在预览模式下，你就能实时看到查询结果。

  * **DataviewJS：** 如果你对 JavaScript 比较熟悉，可以用这个强大的 API 来进行更高级的操作，比如复杂的数据计算和动态渲染。

  * **Inline JS Expressions：** 这让你可以执行任意的 JavaScript 代码，适合那些想要进行深度定制的用户。
