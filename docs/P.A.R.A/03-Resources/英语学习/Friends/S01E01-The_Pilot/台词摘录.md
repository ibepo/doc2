# Friends S01E01 经典台词摘录

## 台词 1：Ross 的"口是心非"

**场景**：Ross 说自己很好，但显然不是

> "I'm fine. Really, I'm fine."
> （我很好，真的，我很好。）

**分析**：
- 这是典型的"口是心非"表达
- 重复说 "really" 说明在掩饰
- 在真实对话中，说"我很好"的人通常不好

**跟读练习**：

- [ ] 能脱稿说出来

**分析**：
