# 英语学习计划 - Friends（老友记）

## 学习目标
- 从四级水平 → 能听懂日常对话
- 能看懂 Friends 不开英文字幕
- 学会日常口语表达

## 学习材料
- **主教材**：Friends Season 1（10 集）
- **辅助材料**：词汇表（本 vault）、单词书（纸质参考）
- **时间投入**：每天 2 小时

## 学习方法：3 遍法

每集内容看 3 遍：

### 第 1 遍：理解剧情（20 分钟）
- ✅ 开英文字幕
- ❌ 关中文字幕
- 目标：理解剧情，标记生词

### 第 2 遍：跟读模仿（30 分钟）
- 开英文字幕
- 角色说话时，你同时说出来
- 标记喜欢的表达

### 第 3 遍：听写+笔记（50 分钟）
- 关字幕，听写 5-10 句
- 在 vault 做笔记
- 整理词汇表
