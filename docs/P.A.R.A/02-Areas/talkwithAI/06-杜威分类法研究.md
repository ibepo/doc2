# 杜威分类法研究

杜威十进分类法（Dewey Decimal Classification, DDC）是由美国图书馆学家麦尔威·杜威于 1876 年创立的图书馆分类系统，是目前世界上影响最大、用户最多的图书馆分类法之一。

> [!info] 核心价值
> DDC 不仅是一种图书分类工具，更是一种**系统化知识组织的方法论**。它通过十进制层级系统将人类全部知识结构化，使信息检索变得高效且可预测。

---

## 01 基本概述

### 1.1 起源与发展

| 维度 | 信息 |
|------|------|
| **创始人** | 麦尔威·杜威 |
| **创立时间** | 1873 年构思，1876 年正式出版 |
| **管理维护** | OCLC (Online Computer Library Center) |
| **当前版本** | DDC 23 (2011)，持续在线更新 |
| **全球使用** | 139+ 国家和地区，20万+ 图书馆 |

### 1.2 设计哲学

杜威最初将人类知识分为三大部分：
1. **记忆（历史）** → 900-999
2. **想象（文艺）** → 800-899
3. **理性（哲学、科学）** → 000-799

然后将这三部分倒置排列，展开为十个主类。

> [!tip] 设计原则
> DDC 遵循 **MECE 原则**：相互独立（Mutually Exclusive），完全穷尽（Collectively Exhaustive）。每个知识点都应该有且只有一个正确的位置。

## 03 编号系统

### 3.1 层级结构

杜威分类法采用**严格的十进制层级体系**：

```
000-099    第一层：10 个主要学科
00-99      第二层：每个学科分为 10 个部（100 个中类）
0-9        第三层：每个部分为 10 个小类（1000 个小类）
小数点后    第四层：无限扩展细分
```

### 3.2 编号规则详解

#### 基本编号结构

| 位数 | 含义 | 示例 |
|------|------|------|
| **第 1 位** | 主要学科 | 5xx = 自然科学 |
| **第 2 位** | 具体学科 | 50x = 数学, 51x = 天文学 |
| **第 3 位** | 细分领域 | 510 = 代数, 511 = 算术 |
| **小数点后** | 进一步细分 | 510.12, 595.789 |

#### 完整索书号

```
分类号 + 作者号（或书名号）

示例：595.789/BRO
       ↓         ↓
   分类号   作者前三个字母
```

> [!note] 作者号
> 作者号通常是作者姓氏的前三个字母。如果书名是主要识别标识（如百科全书），则使用书名的前三个字母。

### 3.3 排序原则：杜威顺序

**关键规则**：逐位比较，不是按整个数字排序

```bash
# 错误的按数字大小排序
331.0123
331.200    ❌ 错误：331.2 > 331.016
331.0413

# 正确的逐位比较（杜威顺序）
331.0123
331.016    ✅ 正确
331.0413
331.042
331.100
331.198
331.200
```

**理解方式**：想象所有数字长度相同（补零）

```
331.0120
331.0160
331.0413
331.0420
331.1000
331.1980
331.2000
```

## 05 使用方法

### 5.1 分类原则

#### 按学科归类，而非按主题

**核心规则**：一本书应该按其**被使用的学科**分类，而不是其来源学科

| 书籍 | 主题 | 学科用途 | 分类号 |
|------|------|---------|--------|
| 《化学导论》 | 化学 | 化学专业教材 | 540（化学） |
| 《化学工程原理》 | 化学 | 工程学教材 | 660（化学工程） |
| 《有机化学合成》 | 化学 | 化学研究 | 547（有机化学） |
| 《家庭化学实验》 | 化学 | 家庭教育 | 607（科学教育） |

### 5.2 图书管理员分类流程

```
1. 分析图书内容
   ↓
   确定主要学科和次要主题

2. 查找主类
   ↓
   在 10 个主类中确定范围（000-900）

3. 定位细目
   ↓
   使用《杜威分类法手册》找到精确编号

4. 添加复分号
   ↓
   应用地区、时间、形式等复分表

5. 构建索书号
   ↓
   组合分类号 + 作者号

6. 上架
   ↓
   按杜威顺序排列
```

### 5.3 读者查找方法

> [!tip] 实用技巧
> 在图书馆查找图书时，先在检索系统找到索书号，然后按以下步骤定位：

```
示例：查找《时间简史》，索书号 530.11/HAW

步骤 1：找到 500-599 区（自然科学）
步骤 2：找到 530-539 区（物理学）
步骤 3：找到 530.11（理论物理学）
步骤 4：按字母找到 HAW（作者霍金）
```

## 07 优点与局限

### 7.1 优点 ✅

| 优点 | 说明 |
|------|------|
| **结构清晰** | 十进制层级系统，易于理解 |
| **语言无关** | 数字标记，超越语言障碍 |
| **层级合理** | MECE 原则，从一般到特殊 |
| **扩展性强** | 小数点后可无限细分 |
| **用户友好** | 用户可独立浏览和查找 |
| **全球通用** | 多语言支持，跨国协作 |
| **持续更新** | 140 多年不断适应新知识 |

### 7.2 局限性 ⚠️

| 局限性 | 说明 |
|--------|------|
| **西方中心** | 主要反映西方知识体系，非西方文化领域分类不够细致 |
| **学科僵化** | 跨学科主题处理困难 |
| **新兴学科** | 新兴领域可能归类不当，需要等待更新 |
| **维护成本** | 需要持续更新和翻译，订阅费用较高 |
| **竞争体系** | LCC（美国国会图书馆分类法）在大学更常用 |

### 7.3 与其他分类法的比较

| 分类法 | 使用范围 | 特点 | 适用场景 |
|--------|---------|------|---------|
| **DDC** | 公共图书馆、学校图书馆 | 数字编码、十进制 | 易于用户浏览 |
| **LCC** | 大学图书馆、研究图书馆 | 字母+数字、专业性强 | 学术研究 |
| **中图法** | 中国图书馆 | 字母+数字、本土化 | 中文文献 |
| **国会图书馆主题词** | 编目索引 | 字母顺序、描述性强 | 主题检索 |

## 08 知识管理应用

### 8.1 唯一维度分类原则

从 DDC 中可以借鉴的核心理念：

> [!quote] 分类原则
> **唯一维度，粗放分类**

- **唯一维度**：不要同时按时间、主题、状态等多个维度分类
- **粗放分类**：不要过度细分，保持简洁

### 8.2 杜威数字编码系统

应用于个人文件管理：

```yaml
# 错误的多维度分类
工作/
  2024/
    项目A/
      财务/
        发票/
        报销/
    项目B/
  2025/

# 正确的唯一维度分类
工作/
  01-项目A/
  02-项目B/
  03-日常事务/
  99-归档/
```

### 8.3 实际应用示例

#### 笔记系统

| 学习内容 | 难度 | 时间 |
|---------|------|------|
| **理解十大主类** | ⭐ 低 | 10 分钟 |

#### 对于图书馆用户

1. **了解大类** - 记住 10 个主要分类
2. **使用索引** - 利用图书馆的在线目录系统
3. **浏览相关区域** - 找到一本书后，浏览相邻区域

#### 对于知识管理爱好者

1. **借鉴原理** - 采用"唯一维度"和"粗放分类"原则
2. **数字编码** - 使用数字而非文字编码提高效率
3. **层级组织** - 建立清晰的层次结构

#### 对于研究者

1. **深度学习** - 参考《DDC 23 简介》和术语表
2. **在线资源** - 访问 Dewey 博客和官方文档
3. **参与讨论** - 加入 OCLC Dewey 社区论坛

## 10 总结与启示

### 10.1 核心价值

杜威分类法是**图书馆学的里程碑成就**，它的价值不仅在于分类图书，更在于：

1. **将人类知识结构化** - 通过层级系统组织全部知识
2. **促进信息发现** - 让用户能够高效地浏览和检索
3. **跨文化通用** - 数字标记超越语言障碍
4. **持续演进** - 140 多年来不断适应新的知识领域

### 10.2 设计启示

> [!tip] 杜威分类法的设计哲学
>
> 1. **简单性** - 十进制，易于理解和使用
> 2. **可扩展性** - 小数点后无限细分
> 3. **一致性** - 统一的编号规则
> 4. **用户导向** - 以用户检索为核心目标
> 5. **持续进化** - 随知识发展而更新

### 10.3 实践建议

**对于知识管理系统设计**：

```yaml
设计原则:
  - 唯一维度: 避免多维分类
  - 层级结构: 清晰的父子关系
  - 编码系统: 数字优先，易排序
  - MECE原则: 相互独立，完全穷尽
  - 用户友好: 考虑实际使用场景
  - 可扩展性: 预留发展空间
```

**对于个人效率提升**：

- 使用数字编码替代文字编码
- 建立清晰的层级文件夹结构
- 定期回顾和调整分类体系
- 保持简单，不要过度分类
