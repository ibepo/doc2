# 【笔记法】PARA 实战：从被笔记"困住"到让笔记为自己打工

## 核心观点
PARA 不是分类知识，而是分类"我要对这些东西做什么"——所有内容都归到「离行动最近的那一层」。

## 关键要点
- **P - Projects（项目）**：有明确目标、有截止时间的事情
- **A - Areas（领域）**：持续进行、没有明确结束时间的职责
- **R - Resources（资源）**：将来可能用到的参考资料
- **A - Archives（归档）**：暂时不用，但也不想删掉

**关键原则**：你不是在分类知识，你是在分类「我要对这些东西做什么」。

## 我的理解 / 批注
这篇文章戳中了我：
- 以前我总以为笔记多是好事，但作者说"笔记在反过来记住我"，太真实了
- 我收藏了很多文章，但真正能用上的很少——这就是在"囤积"而不是"管理"
- PARA 的精髓不是完美的分类结构，而是**让每条笔记都有一个明确的"用途"**

和这个 vault 的关系：
- 这个 vault 已经在用 PARA 结构了
- `03-Resources/微信公众号/` 就是一个典型的 Resources 区
- 现在做的"知识卡片"应该放到 `02-Areas/` 下，因为我会长期维护这个认知

## 可能的应用场景
- **写作**：写文章时，直接从 Projects 里找相关笔记
- **学习**：学新东西时，在 Areas 下建主题，笔记沉淀进去
- **工作**：每个项目一个文件夹，做完后 Archives
