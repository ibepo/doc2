## 📱 快速命令参考

### FFmpeg基本命令
```bash
# 提取首帧（JPG）
ffmpeg -i input.mp4 -frames:v 1 -q:v 2 image.jpg

# 提取首帧（HEIC - Mac）
ffmpeg -i input.mp4 -frames:v 1 -q:v 2 -c:v hevc image.heic

# 截取前3秒视频
ffmpeg -i input.mp4 -t 3 -c copy video.mov

# 转换为高质量H.264
ffmpeg -i input.mp4 -t 3 -c:v libx264 -crf 23 video.mp4
```

### Python脚本核心代码
```python
# 核心转换函数
def convert_mp4_to_livephoto(input_path, output_dir="."):
    # 提取首帧
    subprocess.run([
        'ffmpeg', '-i', input_path,
        '-frames:v', '1', '-q:v', '2',
        'image.jpg'
    ], check=True)

    # 截取视频
    subprocess.run([
        'ffmpeg', '-i', input_path,
        '-t', '3', '-c', 'copy',
        'video.mov'
    ], check=True)
```

## 💡 优化技巧

### 文件大小优化
```bash
# HEIC图片（高质量）
ffmpeg -i input.mp4 -frames:v 1 -q:v 2 image.heic

# H.264视频（平衡质量大小）
ffmpeg -i input.mp4 -t 3 -c:v libx264 -crf 23 video.mov

# 降低分辨率（如果不需要高质量）
ffmpeg -i input.mp4 -t 3 -vf "scale=1920:1080" video.mp4
```

### 质量优化
```bash
# 选择最佳静态帧
# 1. 在视频播放器中预览
# 2. 选择最清晰、最自然的瞬间
# 3. 避免快速移动的场景

# 视频质量设置
# -crf 18-28：18最佳质量，28最小文件
# 推荐值：23（平衡质量与大小）
```
