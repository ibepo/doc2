## 🚀 快速开始

### 最简单方法（iOS用户）
1. 打开App Store
2. 搜索"LivePix"并购买($4.99)
3. 导入MP4视频
4. 选择最佳静态帧
5. 导出并设为壁纸

### 最免费方法（Mac用户）
1. 打开iMovie
2. 截取视频前3秒
3. 导出为MOV
4. 用预览提取首帧
5. 手动组合文件

### 最灵活方法（开发者）
```bash
# 使用提供的Python脚本
python mp4_to_livephoto.py input.mp4
```

## 📋 常见问题解答

### Q: 哪种方案质量最好？
**A:** LivePix App 质量最佳，因为它专门为iOS优化。

### Q: 有没有完全免费的方案？
**A:** Mac用户可使用iMovie + 手动组合完全免费。

### Q: 能批量转换吗？
**A:** Python脚本支持批量处理，其他工具大多需要单个处理。

### Q: Windows有好的方案吗？
**A:** 格式工厂 + FFmpeg 是目前最好的Windows方案。

### Q: 为什么我的Live Photo不播放？
**A:** 检查文件名是否一致、格式是否正确、设备是否支持。

## 🎨 创意灵感

### 适合作为Live Photo的内容
- **自然风光**：日出日落、海浪、云彩
- **城市夜景**：车流光轨、霓虹灯
- **温馨时刻**：家人、宠物静态瞬间
- **艺术创作**：慢动作、延时摄影

### 避免使用的内容
- 快速闪烁的场景
- 晕眩的旋转效果
- 过于复杂的动态内容
