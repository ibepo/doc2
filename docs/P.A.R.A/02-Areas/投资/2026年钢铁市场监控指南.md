# 2026年钢铁市场监控指南

## 📊 监控总览

基于2026年钢铁市场"新周期开启，景气扩张，价格中枢上移"的核心判断，建立全方位监控体系，重点关注以下三大维度：

---

## 🌐 宏观面监控指标

### 1. 政策环境监测
**监测频率**：每日/每周
**关注重点**：
- **国家政策**
  - 财政政策：专项债发行进度、财政支出力度、地方政府化债进展
  - 货币政策：利率变动、MLF/逆回购操作、信贷投放数据
  - 产业政策：钢铁产能置换政策、环保限产政策、出口退税政策

- **国际政策**
  - 美联储政策：利率决议、资产负债表变化、美元指数
  - 欧洲央行：欧元区财政刺激政策
  - 日本央行：货币政策转向信号

**数据来源**：
- 央行官网、财政部官网
- 美联储、欧洲央行、日本央行官网
- 路透社、彭博社政策跟踪

### 2. 经济指标监测
**监测频率**：每月/每季度
**关注重点**：
- **国内经济**
  - GDP增速、PMI指数（制造业/非制造业）
  - 固定资产投资：制造业投资、基建投资、房地产投资
  - 出口数据：钢材出口量、主要出口国需求变化
  - 工业增加值：钢铁行业增加值增速

- **国际经济**
  - 全球制造业PMI
  - 主要经济体（美国、欧盟、日本）经济数据
  - 全球贸易活跃度指数

**预警阈值**：
- PMI连续2个月低于50预警经济下行风险
- 固定资产投资增速低于5%预警投资不足
- 出口增速下降10%以上预警外需减弱

### 3. 周期共振监测
**监测频率**：每周
**关注重点**：
- **国内周期指标**
  - "十五五"规划项目落地情况
  - 信用扩张速度（M2增速、社融规模）
  - 政府项目开工率和投资进度

- **国际周期指标**
  - 美元指数走势
  - 全球大宗商品CRB指数
  - 贵金属价格走势（黄金、白银）

**共振信号**：
- 国内政策宽松 + 美元宽松 = 强共振看涨
- 国内收紧 + 美元收紧 = 强共振看跌
- 一松一紧 = 需要判断主导因素

## 📈 技术面监控指标

### 1. 价格监测
**监测频率**：每日/实时
**关注重点**：
- **期货价格**
  - 螺纹钢期货主力合约价格
  - 铁矿石期货主力合约价格
  - 焦炭、焦煤期货价格
  - 价格波动率和持仓量变化

- **现货价格**
  - 主要钢材品种（螺纹钢、线材、热卷）现货价格
  - 铁矿石进口价格（62%品位、65%品位）
  - 焦炭、焦煤现货价格
  - 区域价差（南北方价差、华东华南价差）

**技术分析关键位**：
- 支撑位：前低、均线支撑、趋势线
- 阻力位：前高、均线阻力、心理关口
- 波动率：日波动超过3%需要重点关注

### 2. 供需监测
**监测频率**：每月/每季度
**关注重点**：
- **供给端**
  - 粗钢日产量、周产量、月产量
  - 高炉开工率、电炉开工率
  - 钢厂库存、社会库存
  - 产能利用率变化

- **需求端**
  - 房地产新开工面积、施工面积
  - 基建项目落地情况
  - 制造业PMI新订单指数
  - 汽车产量、家电产量等下游行业数据

**关键监控点**：
- 粗钢产量：9.8亿吨为年度基准线
- 铁矿石库存：高于1.4亿吨预警供应充足
- 钢材库存：连续4周上升预警需求不足

### 3. 资金流向监测
**监测频率**：每日/每周
**关注重点**：
- **期货市场**
  - 前20名机构持仓变化
  - 多空持仓比变化
  - 成交量变化、持仓量变化
  - 资金流入流出情况

- **股票市场**
  - 钢铁板块资金流向
  - 龙头股票表现（宝钢、鞍钢等）
  - 市场情绪指标

**资金信号**：
- 连续3天净流入 = 看涨信号
- 连续3天净流出 = 看跌信号
- 持仓比持续上升 = 多头信心增强

## 📢 舆情与情绪监控

### 1. 新闻舆情监测
**监测频率**：每日
**监测渠道**：
- **官方媒体**：新华社、人民日报、经济日报
- **行业媒体**：我的钢铁网、中国钢铁工业协会、冶金信息网
- **财经媒体**：财新网、第一财经、21世纪经济报道
- **国际媒体**：路透社、彭博社、华尔街日报

**关注关键词**：
- 政策类：产能置换、环保限产、出口退税、化债
- 经济类：PMI、固定资产投资、出口数据、信贷
- 周期类：新周期、景气度、复苏、扩张
- 价格类：价格中枢、上移、探底、反弹

**情绪评估**：
- 极度悲观：负面新闻占比>70%
- 谨慎乐观：负面新闻占比30-70%
- 乐观情绪：负面新闻占比<30%

### 2. 社交媒体监测
**监测频率**：每日
**监测平台**：
- **专业平台**：雪球、东方财富股吧、期货圈
- **社交平台**：微博、微信、知乎
- **国际平台**：Twitter、LinkedIn、TradingView

**关注指标**：
- 热度指数：相关话题讨论量、转发量
- 情绪指数：正面/负面评论比例
- 专业度：行业专家参与度、专业评论质量
- 国际关注度：外资评论、国际机构观点

**预警信号**：
- 突发负面舆情：股价/价格3天内下跌>5%
- 专业观点分歧：多空观点比例>3:1
- 国际机构一致看空/看多

### 3. 市场预期监测
**监测频率**：每周/每月
**监测方式**：
- **分析师调研**：机构分析师观点汇总
- **问卷调查**：行业人士预期调查
- **期货贴水**：期现价差反映市场预期
- **期权波动率**：隐含波动率变化

**预期指标**：
- 价格预期：未来3个月、6个月、12个月价格预期
- 周期预期：周期见顶/见底时间预期
- 政策预期：对政策松紧的预期

## 🚨 预警机制

### 1. 红色预警（高风险）
**触发条件**：
- PMI连续3个月低于45
- 房地产投资增速下降>15%
- 钢材库存连续6周上升>20%
- 国际机构一致看空
- 突发重大政策转向

**应对策略**：
- 减少仓位，控制风险
- 观望为主，等待信号
- 关注政策应对措施

### 2. 橙色预警（中风险）
**触发条件**：
- PMI连续2个月低于50
- 价格波动率超过5%
- 资金连续流出>5天
- 负面舆情占比>60%

**应对策略**：
- 适度减仓，控制仓位
- 密切关注关键支撑位
- 做好止损准备

### 3. 黄色预警（提醒）
**触发条件**：
- 重要数据发布前1-2天
- 政策会议期间
- 节假日前后

**应对策略**：
- 降低操作频率
- 避免追涨杀跌
- 关注市场情绪变化
