## ⚙️ 技术参数要求

### 📱 文件规格
- **图片**: HEIC格式，3024×4032
- **视频**: MOV格式，3秒，H.264编码
- **总大小**: ≤45MB（建议≤20MB）
- **时长**: 严格3秒（锁屏壁纸）

### 🎯 质量优化参数
```bash
# FFmpeg最佳参数
ffmpeg -i input.mp4 \
  -vf "scale=3024:4032" \    # iPhone分辨率
  -t 3 \                     # 3秒时长
  -c:v libx264 \             # H.264编码
  -crf 23 \                  # 质量平衡
  -preset medium \          # 编码速度
  -c:a aac \                 # 音频编码
  -b:a 128k \               # 音频比特率
  output.mov                 # 输出文件
```

## 🔧 故障排除

### ❌ 问题：无法设为壁纸
**检查清单**：
- [ ] 文件大小≤45MB
- [ ] 视频时长=3秒
- [ ] 格式为HEIC+MOV
- [ ] 文件名完全一致
- [ ] iPhone存储空间充足

**解决命令**：
```bash
# 检查文件类型
file frame.heic
file frame.mov

# 检查文件大小
ls -lh frame.*

# 检查视频时长
ffprobe -v quiet -show_format -show_streams frame.mov | grep duration
```

### ❌ 问题：动画卡顿
**解决方案**：
1. 压缩文件至≤20MB
2. 降低分辨率至1920×1080
3. 关闭其他应用释放内存
4. 重启iPhone

### ❌ 问题：转换失败
**排查步骤**：
```bash
# 检查视频编码
ffprobe -v quiet -select_streams v:0 -show_entries stream=codec_name input.mp4

# 如果不是H.264，转换格式
ffmpeg -i input.mp4 -c:v libx264 -preset fast temp.mp4
```
