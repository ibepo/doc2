## 🎯 Live Photo基础认知

### 📱 什么是Live Photo

Live Photo是苹果公司在iOS 9推出的动态图片功能，它本质上是：
- **静态部分**: 一张高质量HEIC格式图片
- **动态部分**: 一段3秒的MOV格式视频
- **文件组合**: 两个文件必须同名，系统自动组合显示

### 🔧 技术规格要求

| 参数 | 要求 | 说明 |
|------|------|------|
| **文件格式** | HEIC + MOV | 必须配套使用 |
| **图片分辨率** | 3024×4032 | 建议使用原相机分辨率 |
| **视频时长** | 严格3秒 | 锁屏壁纸必须3秒 |
| **文件大小** | ≤45MB | 建议≤20MB以获得最佳性能 |
| **视频编码** | H.264 | iOS原生支持格式 |
| **系统要求** | iOS 11+ | iPhone 6s及以上 |

### 🏆 方案四：编程实现（推荐指数：⭐⭐⭐）

#### 🐍 Python + FFmpeg自动化脚本

**适用场景**：
- 需要批量处理大量视频
- 追求最高质量转换
- 有一定编程基础

**核心脚本**：
```python
import os
import subprocess
from PIL import Image
import ffmpeg

def mp4_to_live_photo(mp4_path, output_dir):
    """
    MP4转Live Photo的Python实现
    """
    try:
        # 1. 提取视频的第一帧作为静态图片
        (
            ffmpeg
            .input(mp4_path)
            .filter('vframes', '1')
            .output(os.path.join(output_dir, 'frame.jpg'), vframes=1)
            .overwrite_output()
            .run(capture_stdout=True, capture_stderr=True)
        )

        # 2. 转换图片为HEIC格式
        image = Image.open('frame.jpg')
        heic_path = os.path.join(output_dir, 'frame.heic')
        image.save(heic_path, 'HEIC')

        # 3. 提取3秒视频片段
        video_output = os.path.join(output_dir, 'frame.mov')
        (
            ffmpeg
            .input(mp4_path)
            .output(video_output, t=3, vcodec='libx264', acodec='aac')
            .overwrite_output()
            .run(capture_stdout=True, capture_stderr=True)
        )

        print(f"转换完成: {mp4_path}")
        return True

    except Exception as e:
        print(f"转换失败: {e}")
        return False

# 批量处理示例
video_files = ['video1.mp4', 'video2.mp4', 'video3.mp4']
for video_file in video_files:
    mp4_to_live_photo(video_file, './output')
```

**使用说明**：
1. 安装依赖：`pip install ffmpeg-python pillow`
2. 将脚本和视频文件放在同一目录
3. 运行脚本：`python converter.py`
4. 通过iCloud或数据线传输到iPhone

## 🎨 壁纸应用优化指南

### 🔍 锁屏壁纸特殊要求

#### 严格的技术标准
1. **时长必须精确3秒**
   - 少于3秒：动画不完整
   - 多于3秒：系统自动截断

2. **分辨率匹配**
   ```bash
   # iPhone 14 Pro: 2556×1179
   # iPhone 13: 2532×1170
   # iPhone 12: 2532×1170
   ```

3. **文件大小控制**
   - 最佳：10-20MB
   - 最大：45MB
   - 过大可能导致壁纸无法设置

#### 视觉效果优化

1. **内容选择**：
   - 适合静态展示的主体
   - 动画部分不要太复杂
   - 避免闪烁或快速变化

2. **技术优化**：
   ```bash
   # 推荐的视频参数
   ffmpeg -i input.mp4 \
     -vf "scale=3024:4032" \  # 匹配iPhone分辨率
     -t 3 \                    # 3秒时长
     -c:v libx264 \           # H.264编码
     -crf 23 \                # 质量平衡
     -preset medium \         # 编码速度
     -c:a aac \               # 音频编码
     -b:a 128k \              # 音频比特率
     output.mov
   ```

### 🏠 主屏壁纸注意事项

1. **动态效果**：
   - Live Photo在主屏会自动播放
   - 可以设置不同的循环效果（慢动作、循环等）

2. **显示效果**：
   - 壁纸会随通知栏动态调整
   - 确保主体不会被遮挡

## ⚠️ 常见问题与解决方案

### ❌ 问题1：转换后的Live Photo无法设为壁纸

**原因分析**：
- 文件格式不正确
- 文件过大
- 视频编码不支持

**解决方案**：
```bash
# 检查文件格式
file frame.heic    # 确认是HEIC格式
file frame.mov    # 确认是MOV格式（H.264编码）

# 重新转换，确保参数正确
ffmpeg -i input.mp4 \
  -vf "scale=3024:4032" \
  -t 3 \
  -c:v libx264 \
  -crf 23 \
  output.mov
```

### ❌ 问题2：动态效果卡顿或延迟

**原因分析**：
- 文件过大
- 视频分辨率过高
- iPhone性能不足

**解决方案**：
1. 压缩文件大小（≤20MB）
2. 降低分辨率
3. 关闭其他后台应用

### ❌ 问题3：批量转换失败

**原因分析**：
- 文件名冲突
- 内存不足
- 编码器不支持

**解决方案**：
```python
# 改进的批量转换脚本
def batch_convert(video_files, output_dir):
    for i, video_file in enumerate(video_files):
        # 使用唯一文件名避免冲突
        output_name = f"live_photo_{i+1}"
        mp4_to_live_photo(video_file, output_dir, output_name)
```
