## 节目摘要

本期的连点呈现，将两个与这节目呼应的话题：

### 1. Attention is not all you need

这是和戴雨森聊的 agent 那期播客的标题。他讲的是 agent 这种有自主性又能完成任务的工具，可以解放人的注意力，让每个人的工作或生产潜力大幅提升。

雨森说这是**工作的 scaling law**，进一步可能是资金转化为生产力的 scaling law。

**卡兹克分享的这些实操案例，就是 "Attention is not all you need" 的一个具体实现。**

他也提到，如果不是因为从去年底到今年逐渐完善的更多 AI 自动化流程，他也可能很难找出这么长的时间来录播客。

### 2. 模型和产品之间的关系

这也是我们在 Agent 那期和之前与 MiniMax 的严俊杰还有百川的王小川的访谈中都聊到过的话题。

关于这个问题，向来有两派观点：

#### 观点一：模型吞噬产品

认为模型及产品，模型能力上升会吞噬掉一些产品。

比如本期聊到的 **Jasper**：
- 这是一个 ChatGPT 之前就已经出现的明星 AI 产品
- 主要用于写营销邮件
- 它用的是 OpenAI 的模型
- 但是在 GPT 包括 Claude、Solid 等更多更强的模型出现或升级后，Jasper 一度受到了冲击

和卡兹克录这期时，GPT-4o 还没有释放文生图功能，而现在也有很多人开始担心之前学习 MidJourney 或 Stable Diffusion 的经验会不会变得没用了。

#### 观点二：产品仍有价值

认为可有的用处，那些基于其他模型来做的产品，会因为对需求的洞察、独特的设计思路或者工程优化而有一定的竞争力。

**戴雨森在 Agent 那期节目中提到，专注做应用至少有两个好处：**

1. 一个应用可以混用多种模型，发挥各个模型的长处
2. 在用户心智上，一些成功的产品，有可能让目标客户有依赖、有黏性

**Perplexity 和 Cursor 都是比较好的例子。**

### 主办方的感受

我自己的一个感受是，**有模型能力的公司可能确实更有主动权**，尤其是同时做大模型和产品的公司。OpenAI 和一众巨头就是典型。

**案例：GPT-4o 文生图功能**

- 这次 GPT-4o 释放文生图功能后，反馈非常火爆
- 但 OpenAI 并没有在第一时间对外释放 API
- 也没有在 ChatGPT 的免费版里放这个功能
- 这就导致 ChatGPT 的付费版成为了市场的独供
- 从社交媒体上的大量 GPT-4o 生成图来看，这次拉新的效果应该很不错，而且是实打实的付费用户

**结论**：

如果某个产品是大模型公司在提升模型能力的主方向或者主航道上，就很可能面临更严酷的环境。

- 这次是更好的文生图
- 更好的通用 agent 应该也是各个模型的必争之地
